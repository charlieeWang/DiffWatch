# DiffWatch

不用一直重整網頁，也能知道你在意的內容有沒有變。

DiffWatch 是一個 Chrome 擴充功能。選好要追蹤的區域後，它會定期在背景開啟網站、比較內容；發現變更時通知你，並留下前後對照，方便回頭查看。

## 開始使用

1. 下載專案，在 Chrome 開啟 `chrome://extensions`。
2. 打開「開發人員模式」，按「載入未封裝項目」，選擇專案內的 **`dist` 資料夾**。
3. 開啟想追蹤的網站，點 DiffWatch →「監控目前頁面」。也可以在管理頁新增任務，按「開啟網頁並選取區域」。
4. 用「選取監控區域」挑好範圍；倒數、廣告等不想比較的內容，可用「忽略區塊」排除。
5. 按「下一步：設定監控」，設定檢查間隔，先「授權並驗證預覽」，再「授權並儲存」。

任務顯示「監控中」後就設定好了。第一份內容只會作為比較基準，之後有變更才通知。

## 日常怎麼用？

- **原網站與管理頁都可以關閉**，保持 Chrome 執行即可。每次檢查會另開背景分頁，完成後關閉。
- **沒有通知不一定是沒檢查**，也可能只是內容沒變；管理頁能看到最近嘗試與成功時間。
- 想看哪裡變了，就打開「歷史」。已讀、全部已讀與清除歷史都在這裡；清除歷史會保留目前比較基準。
- 不想繼續追蹤時，關掉任務名稱旁的開關即可。

## 先知道這幾件事

DiffWatch 比較的是**文字、連結與圖片網址**，不是截圖。圖片網址沒變但圖片本身換了、只改顏色或版面，都不會因此通知。

它需要 Chrome 120 以上，適用於一般 HTTP(S) 網頁。Chrome 關閉、電腦睡眠或離線時不會持續檢查；排程也可能延後，不保證捕捉間隔內的短暫變化。登入、留言與延遲載入等動態內容，可能需要調整選區或載入等待時間。

任務與歷史保存在本機，**未加密**，也沒有雲端同步。目前支援桌面通知，**尚不支援寄信**。授權網站時，Chrome 允許的是整個來源的存取，不只選取的區域。
