# DiffWatch

追蹤網頁內容變動的 chrome 擴充套件。

選好追蹤區域後，會定期在背景開啟網站、比較內容變化。

發現變更時會跳出通知，並存入 diff 歷史紀錄。

## How to use

1. 下載專案後，在 Chrome 開啟 `chrome://extensions`。
2. 打開「開發人員模式」，按「載入未封裝項目」，指定專案內的 **`dist` 資料夾**。
3. 開啟想追蹤的網站，點 DiffWatch →「監控目前頁面」。也可以在管理頁新增任務後，按「開啟網頁並選取區域」。
4. 用「選取監控區域」挑好範圍；接者，可用「忽略區塊」排除範圍內不需要追蹤的區塊。
5. 按「下一步：設定監控」跳至設定頁。
6. 設定檢查間隔，先按「授權並驗證預覽」確認追蹤區塊內容，再按下「授權並儲存」。

任務顯示「監控中」後即設定完畢。

初始設定會作為一開始的比較基準，未來有變化才會通知。

## 使用 Tips

- 完成設定後，只要保持 Chrome 執行即可，**原網站與管理頁都可以關閉或自由使用**。每次檢查會另開背景分頁，完成後自動關閉。不影響一般使用。
- 若內容沒有變化，便不會跳出通知；從管理頁能看到最近嘗試與成功的時間記錄。
- 「歷史」可以查看變更紀錄。
- 任務名稱旁的開關可以隨時開關追蹤任務。

## 注意事項

DiffWatch 是以**文字、連結與圖片網址**作為比較基準，而非比較截圖。若圖片不同但圖片網址相同、只變更顏色或版面，都不收到通知。
需要 Chrome 120 以上，適用於一般 HTTP(S) 網頁。

**Chrome 關閉、電腦睡眠或離線時，檢查也會停止；排程也可能會延後。** 
登入、留言與延遲載入等動態內容，可能需要調整載入等待時間。

任務與歷史保存在本機，**未加密**，也沒有雲端同步。

目前僅支援桌面通知，**尚未支援寄信**。

授權網站時，Chrome 允許的是整個來源的存取，不只選取的區域。
